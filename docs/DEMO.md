# LinkedIn GIF storyboards

<!-- markdownlint-configure-file { "MD013": { "tables": false } } -->

Two silent, looping recordings of the Boldemort editor. The captions mark the
actual toolbar actions, and the ending gives viewers time to read the result.

| Time | [Give your post emphasis](../media/linkedin-formatting.gif) | [Change the lettering](../media/linkedin-random-font.gif) |
| --- | --- | --- |
| 0.0–1.6 s | Show a short plain draft in Markdown mode. | Show a plain draft in the dark theme. |
| 1.6–2.8 s | Select the whole draft and highlight Bold. | Select the whole draft and highlight Random font. |
| 2.8–4.4 s | Apply Bold and switch to copyable Unicode. | Turn Random font on and show the changed lettering through 4.8 s. |
| To 6.8 s | Copy the styled text and show the confirmation. | Turn Random font off and show the restored Latin text from 4.8 s. |

Each GIF is 1080 × 960 pixels at 5 fps. The 34 frames take 6.8 seconds to
play. Both fit the published GIF limits for image attachments. See
[LinkedIn’s supported media types](https://www.linkedin.com/help/linkedin/answer/a564111).

Suggested alt text for the formatting GIF is “Boldemort selects a two-line
draft, applies bold, switches to Unicode, and copies the result.” For the
Random font GIF, use “Boldemort changes selected Latin lettering to mixed
Unicode fonts, then restores the original text on the second click.”

# LinkedIn GIF storyboards

<!-- markdownlint-configure-file { "MD013": { "tables": false } } -->

Two silent, looping recordings of the Boldemort editor in Light mode. Both
show selective formatting, and the ending gives viewers time to read the
result.

| Time | [Give your post emphasis](../media/linkedin-formatting.gif) | [Change the lettering](../media/linkedin-random-font.gif) |
| --- | --- | --- |
| 0.0–1.6 s | Show a two-line plain draft in Markdown mode. | Show a draft with one bold word and plain text. |
| 1.6–2.8 s | Highlight the phrase “launch on Friday”. | Select “changes the lettering”. |
| 2.8–4.4 s | Bold the selected phrase and switch to copyable Unicode. | Turn Random font on for the selected phrase and show the result through 4.8 s. |
| To 6.8 s | Copy the mixed bold and plain text and show the confirmation. | Turn Random font off and show the restored phrase from 4.8 s. |

Each GIF is 1080 × 960 pixels at 5 fps. The 34 frames take 6.8 seconds to
play. Both fit the published GIF limits for image attachments. See
[LinkedIn’s supported media types](https://www.linkedin.com/help/linkedin/answer/a564111).

Suggested alt text for the formatting GIF is “Boldemort bolds the phrase
‘launch on Friday’, leaves the rest plain, and copies the Unicode draft.”
For the Random font GIF, use “Boldemort mixes the lettering in one selected
phrase and restores it on the second click, leaving the rest of the draft
in place.”
